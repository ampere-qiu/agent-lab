# コース全体の流れ { #two-week-course-route }

このローカル教材は、Hugging Face Agents Course Unit 1とそのスターター、Unit 2.1を、Groqとローカル実行に合わせて構成しています。第1〜2週はUnit 1、第03週はUnit 2.1を通して、第2週のsmolagentsとツールの学習を深めます。英語版と日本語版を用意しています。外部のHFレッスンは補足資料で、原典の小テストは外部サイトで取り組みます。

| 週 | 内容 | 完了の根拠 |
| --- | --- | --- |
| [1](week-1-learning-plan.md) | 基礎、ローカル環境の準備、3段階のダミー演習 | ループを説明し、`dummy_agent.py`で実際の関数の観測結果を示す |
| [2](week-2-learning-plan.md) | チャットテンプレート、CodeAgent、時刻・検索ツール | モデルの応答、ツールの直接テスト、エージェントによる呼び出し、根拠を確認した情報源を示す |
| [3](week-3-learning-plan.md) | ターミナル用エージェント、アクション形式、ツール、Agentic RAG | 保存したファイル、直接テスト、ツールの変更、出典に基づく検索・取得の回答を示す |
| [4 — 次回](week-4-preview.md) | エージェントのチームと画像・ブラウザの話題 | 第03週の後に進む |

[独自ツールの課題](first-agent-practical.md#6-optional-create-your-own-tool)は第2週の任意の発展課題です。

## 進み具合を確認するには { #how-to-review-your-progress }

[第1週の確認項目](week-1-learning-plan.md#week-1-completion)、[第2週の実習確認](quizzes.md#finish-the-practical)、[第03週の確認項目](week-3-completion.md)を使います。この教材サイトは進捗、点数、完了状態を保存しません。作成したスクリプトと実行の根拠を振り返り用に残しましょう。言語を切り替えると同じレッスンが開き、作業内容は変わりません。

画像生成と、アカウントが必要な最終テストは除外しています。第2週の独自ツールは任意ですが、第03週には手順に沿って取り組む必須のツール課題があります。Spaceの公開とHFの認定取得は修了の条件ではありません。
