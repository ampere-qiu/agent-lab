# 2週間のコースの流れ { #two-week-course-route }

このローカル教材は、Hugging Face Agents Course Unit 1とそのスターターを、Groqとローカル実行に合わせて構成したものです。既存の内容を2週間に分けています。このソースには、それ以降の週の教材はありません。HFの原典ページは補足資料で、原典の小テスト2つは外部サイト上で取り組みます。

| 週 | 内容 | 時間の目安 | 完了の根拠 |
| --- | --- | --- | --- |
| [1](week-1-learning-plan.md) | 基礎、ローカル環境の準備、3段階のダミー演習 | 3〜4時間 | ループを説明し、`dummy_agent.py`で実際の関数の結果を確認する |
| [2](week-2-learning-plan.md) | チャットテンプレート、CodeAgent、時刻・検索ツール | 3〜4時間 | モデルの応答、直接テスト、エージェントの実行記録、検証した情報源を示す |

[独自ツールの課題](first-agent-practical.md#6-optional-create-your-own-tool)は第2週の任意の発展課題で、目安は30〜60分です。時間は計画用の目安で、制限時間ではありません。環境準備やサービスの制限で長くなる場合があります。

## 進み具合を確認するには { #how-to-review-your-progress }

[第1週の確認項目](week-1-learning-plan.md#week-1-completion)、続いて[第2週の実習確認](quizzes.md#finish-the-practical)を使ってください。この教材サイトは進捗、点数、完了状態を保存しません。作成したスクリプトと実行の根拠を振り返り用に残しましょう。言語を切り替えると同じレッスンが開き、作業内容は変わりません。

画像生成とアカウントが必要な最終テストは除外しています。独自ツール、Spaceの公開、Hugging Faceの認定取得は任意、またはこの教材の範囲外で、修了の条件ではありません。
