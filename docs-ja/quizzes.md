# 小テストと学習の完了確認 { #quick-quizzes-and-completion }

この教材ではHugging Face原典の小テスト2つのみを使います。外部サイトで開き、問題とフィードバックは原典のものを利用します。

| 取り組むタイミング | 活動 |
| --- | --- |
| エージェントの導入を読んだ後 | [小テスト1](https://huggingface.co/learn/agents-course/en/unit1/quiz1) |
| モデル・メッセージ・ツールを読んだ後 | [小テスト2](https://huggingface.co/learn/agents-course/en/unit1/quiz2) |

確認した環境では最終テストにアカウントでのアクセスが必要だったため、この学習経路から除外しています。Hugging Faceの認定取得や最終テストの提出は不要です。ローカルの解説と実習は外部レッスンページに依存しません。

小テストが開かない場合は通常のブラウザータブで開いて再読み込みします。利用できない間はローカル演習を進めてください。このガイドは点数を記録せず、HF公式の認定証も発行しません。

## 実習の完了確認 { #finish-the-practical }

第1週は[ダミーエージェントの確認項目](week-1-learning-plan.md#week-1-completion)を使います。

第2週は[ツール実習](first-agent-practical.md)の後に、次を確認します。

- 実際の時刻ツール呼び出しと、返された時刻を示せる。
- 実際の検索呼び出しを示し、返された関連情報源を開ける。
- モデル、Groq、smolagents、ローカル関数の役割を説明できる。
- ツールのエラーと、正常な観測結果を区別できる。

これは実習の確認項目で、最終テストの代替ではありません。独自ツールは任意で、画像生成は含みません。

テンプレートの正常な応答、停止・再起動の手順も実演し、手動のダミーループとCodeAgentの違いを説明してください。利用できなかった動作確認は未完了と記録し、後で再試行します。[2週間のコースの流れ](course-route.md)も参照してください。
