# 小テストと実習の完了確認 { #quick-quizzes-and-completion }

この教材では、元のHugging Faceの小テスト2回だけを使います。外部サイトで開き、原典の問題とフィードバックを利用します。

| タイミング | 活動 |
| --- | --- |
| エージェントの導入を読んだ後 | [小テスト1](https://huggingface.co/learn/agents-course/en/unit1/quiz1) |
| モデル、メッセージ、ツールを学んだ後 | [小テスト2](https://huggingface.co/learn/agents-course/en/unit1/quiz2) |

確認した環境では最終テストにアカウントへのアクセスが必要だったため、この学習順序からは外しています。Hugging Faceの認定や最終テストの提出は不要です。このサイトのレッスンと実習は、外部レッスンの閲覧に依存しません。

小テストが読み込めない場合は、通常のブラウザーで開いて再読み込みします。外部の演習が使えない間は、ローカル演習を進めてください。このガイドは得点を記録せず、Hugging Face公式の認定証も発行しません。

## 実習の完了条件 { #finish-the-practical }

[ツールを実装・登録](first-agent-practical.md)したら、次を確認します。

- 実際の時刻ツールの呼び出しと、返された時刻を示せる。
- 実際のWeb検索の呼び出しを示し、返された関連資料を開ける。
- モデル、Groq、smolagents、ローカル関数の役割を説明できる。
- ツールのエラーと、成功した観測結果を区別できる。

これは実習の完了確認で、最終テストの代替ではありません。自作ツールは任意で、画像生成は含めません。
