# 第1週 — 基礎・環境準備・ダミーエージェント { #week-1-concepts-setup-and-a-dummy-agent }

今週は、エージェント用フレームワークを使う前に、動作の仕組みをつかみます。

## 学習目標 { #learning-objectives }

第1週を終えたら、モデル・提供サービス・プログラム・ツールの違いを説明し、ローカルのPython環境を準備して、リクエスト → 行動の提案 → 関数の実行 → 観測結果 → 最終応答という流れをたどれるようになります。

## 学習の順序 { #learning-sequence }

1. ターミナルやPythonの編集に慣れていない場合は、[始める前に](before-you-start.md)を読みます。
2. [エージェントの基礎](unit-1-walkthrough.md)を読み、HFの小テスト2つに取り組みます。HFの原典は補足資料です。原典の実験画面が動かなくても、ローカル実習には進めます。
3. [環境を準備](prepare-your-computer.md)します。Python 3.11、ダミー演習用フォルダーと仮想環境、モデル用クライアント、自分のGroqキーを用意します。
4. [3段階のダミーエージェント](dummy-agent-local.md)を作って実行します。モデルへの問い合わせ、提案された行動の確認、Python関数の結果を返す処理を順に試します。

今週はチャット用の完全なテンプレートをダウンロード・設定する必要はありません。ダミー演習の天気は固定のデモデータです。実際の時刻取得と検索は第2週で扱います。

## 第1週の完了確認 { #week-1-completion }

- モデルがツール名を出力しても、実行したことにはならない理由を説明する。
- ダミー演習のフォルダーで、Python 3.11と有効な`.venv`を確認する。
- `python dummy_agent.py`を実行し、最終応答の前に実際の関数の結果が出ることを含め、3段階すべてを示す。
- 停止マーカー、手動の確認、天気がデモデータである理由を説明する。
- 小テスト2つに取り組み、利用できなかった外部活動があれば記録する。このサイトは点数を保存しません。

来週比較できるように`dummy_agent.py`を残してください。APIリクエストが失敗したら、[トラブル対応](run-your-first-agent.md#troubleshooting)で確認してから、そのチェックポイントをやり直します。読んだだけでは実際の通信を確認したことにはなりません。
