# 第1週の学習順序 { #week-1-course-route }

このローカル教材は、Hugging Faceのスターターと概念を、Groq APIとローカル実行に合わせて調整しています。画像生成と、アカウントへのアクセスが必要な最終テストは外しています。

1. [基本設定](prepare-your-computer.md)：Pythonと自分のGroqキー。
2. 基礎：[この教材の説明](unit-1-walkthrough.md)と[元のHugging Faceレッスン](https://huggingface.co/learn/agents-course/en/unit1/introduction)を読み、この教材からリンクしているHFの小テスト2回に取り組む。
3. [ダミー演習の3段階](dummy-agent-local.md)：モデルへのリクエスト、行動の提案、関数の観測結果。
4. [テンプレートのダウンロード](run-your-first-agent.md)と[構成の理解](understand-the-template.md)。
5. [必須の実習](first-agent-practical.md)：時刻取得とWeb検索を登録・検証。
6. [完了確認](quizzes.md#finish-the-practical)。

自作ツールは任意の発展課題です。外部のHFレッスンは補足の原典資料で、実習の前提ではありません。
