# 第2週 — テンプレートを動かし、ツールを使う { #week-2-working-template-and-tools }

[第1週の完了確認](week-1-learning-plan.md#week-1-completion)を終えてから始めます。ダミースクリプト、インストール済みのPython、Groqキーを引き続き使います。

## 学習目標 { #learning-objectives }

第2週を終えたら、チャットテンプレートを入力から応答まで動かし、CodeAgentがループを管理する仕組みを説明できるようになります。ツールを登録・テストし、実行記録と検索で返された情報源に照らして回答を確かめます。

## 用意されているものと、自分がすること { #what-is-supplied }

配布テンプレートには、チャット画面、モデル接続、時刻・検索ツールの実装がすでに入っています。**必須の課題は、その2つのツールをテストして登録し、エージェントが実際に使ったことを示すことです。** 時刻関数や検索処理の本体を自分で書く必要はありません。

「登録」とは、`CodeAgent(...)`の`tools=[...]`というリストにツールを追加し、エージェントから使えるようにすることです。ファイルがあることや、インポートしたことだけでは登録になりません。

| ツール | 配布されているもの | 最初の起動時にエージェントが使える？ | 自分がすること |
| --- | --- | --- | --- |
| `final_answer` | `tools/final_answer.py`に実装済み | はい | 最終結果を返すため、登録したままにする |
| `get_current_time_in_timezone` | `app.py`に実装済み | いいえ | テストし、登録し、実行を確認する |
| `WebSearchTool`（エージェントが使う名前は`web_search`） | `tools/web_search.py`に実装済み。`app.py`でインポート済み | いいえ | テストし、登録し、返された情報源を確かめる |
| `my_custom_tool` | `app.py`に未完成の仮実装だけがある | いいえ | 任意で自分の処理を書き、テストして登録する |
| `get_weather` | このテンプレートには含まれない | いいえ | 第2週の課題ではない。第1週のダミー演習で使った関数 |

変更前のテンプレートでも簡単な質問に応答し、`12 * 8`を計算できます。ただし、配布済みの検索ツールは登録するまで使えません。もっともらしいURLや「検索しました」という発言だけでは、検索が実行された証拠にはなりません。

## 学習の順序 { #learning-sequence }

1. [テンプレートをダウンロードして起動](run-your-first-agent.md)します。専用のフォルダーと仮想環境を使います。`12 * 8`の答えを確認します。画面が開くだけでは、モデルへの接続確認にはなりません。
2. `app.py`を横に開き、[テンプレートの仕組み](understand-the-template.md)を読みます。第1週の手動ループと、自動化されたループを比較します。
3. [用意済みのツールを登録し、テスト](first-agent-practical.md)します。時刻関数を直接テストしてから登録し、エージェントの呼び出しを確認します。検索でも同じ手順を行い、返された情報源を確かめます。
4. 両方のツールを実演し、[完了確認](quizzes.md#finish-the-practical)を行います。
5. 任意で、[独自ツールの作成例](first-agent-practical.md#6-optional-create-your-own-tool)を参考に、実装・説明・テスト・登録まで行います。

## 第2週の完了確認 { #week-2-completion }

チャットの正常な応答、時刻と検索の直接テストと実行記録、根拠を確認したリンクを示してください。モデルの実行場所、ローカルで動くコード、エラーと正常な観測結果の違いを説明し、アプリの停止と再起動も実演します。

検索サービスとGroqの制限は別です。実際の動作を確認できない場合は未完了と記録し、後で再試行します。モデルが記憶から出したリンクは、検索実行の代わりにはなりません。画像生成、Spaceの公開、アカウントが必要な最終テスト、認定取得は必須ではありません。
