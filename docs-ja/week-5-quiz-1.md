# 第5週 · 小テスト1 { #week-5-quiz-1 }

**目標：**エージェントへ進む前に、部品とツールを説明します。`evidence.md`の**Quiz 1**に答えを書いてから、解説を開いてください。[HFの小テスト1](https://huggingface.co/learn/agents-course/en/unit2/llama-index/quiz1)と同じ話題の授業用確認で、HFへ点数は送信しません。

## 1. クエリエンジン { #query-engine }

クエリエンジンと、実行したretrieverはどう違いますか？

??? success "答え1"

    retrieverは候補の文章とスコアを返します。クエリエンジンは、それに加えてモデルが検索情報から回答を作ります。どちらの結果も確認が必要です。

## 2. 関数ツール { #function-tool }

`FunctionTool`はPython関数に何を加えますか？直接呼ぶ場合にLLMは必要ですか？

??? success "答え2"

    名前、説明、入力スキーマを持つツールの窓口を付けます。直接呼び出す場合は、LLMが利用を判断せずに関数を実行できます。

## 3. ツールの集まり { #tool-spec }

`ClassroomToolSpec`は2つのツールを返します。エージェントを何体作りましたか？

??? success "答え3"

    0体です。機能をリストにまとめただけです。エージェントは別に作り、そのリストを渡せます。

## 4. 分かりやすい窓口 { #interface }

「10件の人物像から関心と専門分野を検索する」という説明が、「便利なツール」より適切なのはなぜですか？関数のどの部分が入力形式の情報になりますか？

??? success "答え4"

    具体的な説明があると、モデルは使う場面と得られる情報を判断しやすくなります。関数名、引数名、型注釈、docstringが入力と目的を伝えます。自動で作られたメタデータも確認し、必要なら明確にします。

**次へ進む前に：**実際の出典の文章を1つ示し、どのツールで取り出せるか説明してください。難しい場合は[コンポーネント](week-5-components.md#retrieve)と[ツール](week-5-tools.md#query-tool)へ戻ります。
