# 第5週 · 小テスト2 { #week-5-quiz-2 }

**目標：**エージェントの判断、イベント、状態がどう連携するか説明します。`evidence.md`の**Quiz 2**に答えてから解説を開いてください。[HFの小テスト2](https://huggingface.co/learn/agents-course/en/unit2/llama-index/quiz2)に沿う授業用確認で、点数は送信しません。

## 1. AgentWorkflow { #agent-workflow }

`AgentWorkflow`は何を整理しますか？オブジェクトを作れたことだけで、エージェント間の受け渡しが起きたと言えますか？

??? success "答え1"

    1体以上のエージェント、ツール、許可した受け渡しを整理します。作成は設定を示し、実際の呼び出しや受け渡しの記録が実行を示します。

## 2. 共有する状態 { #context }

保存した質問とチームの計算カウンターを持っていたオブジェクトは何ですか？`ProcessingEvent`とどう違いますか？

??? success "答え2"

    `Context`が共有状態を持ちます。`ProcessingEvent`は型のあるデータを対応するステップへ運び、経路を決めます。どちらも情報を運べますが、ワークフロー内の役割は異なります。

## 3. 会話の記憶 { #memory }

Bobに関する2つのメッセージで、同じ`ctx`を使ったのはなぜですか？新しいContextは自動で名前を知っていますか？

??? success "答え3"

    同じContextで以前のやり取りを保持するためです。新しいContextには先ほどの名前の根拠がありません。名前を推測することと、覚えていることは別です。

## 4. エージェントによるRAG { #agentic-rag }

計算と人物像のツールを持つエージェントは、人物像のクエリエンジンを直接呼ぶ場合とどう違いますか？

??? success "答え4"

    直接呼ぶ場合は決められた検索・回答処理を行います。エージェントは使えるツールから選び、入力も決めます。何を実際に選んだか、戻った根拠が最終回答を支えるかを確認します。

**追加の確認：**`ARITHMETIC CALLS: 1`が出たら、Groqへの問い合わせも1回だけだったと言えますか？

??? success "カウンターの答え"

    言えません。数えるのは計算関数の実行だけです。受け渡しや判断には別のモデル問い合わせが必要な場合があります。リクエスト数やトークン数の計測器ではありません。
