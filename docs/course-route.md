# Two-week course route { #two-week-course-route }

This local course adapts Hugging Face Agents Course Unit 1 and its starter for Groq and local execution. The existing material is split into two weeks; this source contains no later weekly units. External HF lesson pages are optional references. The two original quick quizzes remain external activities.

| Week | Focus | Suggested time | Evidence of completion |
| --- | --- | --- | --- |
| [1](week-1-learning-plan.md) | Concepts, local setup, three-stage dummy agent | 3–4 hours | Explain the loop and run `dummy_agent.py` with a real function observation |
| [2](week-2-learning-plan.md) | Working chat template, CodeAgent, time and search tools | 3–4 hours | A model response, direct tool tests, executed agent calls, and a verified source |

The [custom-tool challenge](first-agent-practical.md#6-optional-create-your-own-tool) is an optional 30–60 minute extension in Week 2. Durations are planning estimates, not timers; setup and service limits may extend them.

## How to review your progress { #how-to-review-your-progress }

Use the [Week 1 checks](week-1-learning-plan.md#week-1-completion), then the [Week 2 practical checks](quizzes.md#finish-the-practical). This documentation site does not store progress, quiz scores, or completion status. Keep your scripts and execution evidence for review. Changing language opens the same lesson and does not change your work.

Image generation and the account-gated final quiz are removed. A custom tool, publishing a Space, and Hugging Face certification are optional or outside this adaptation; they are not completion requirements.
