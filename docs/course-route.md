# Course route { #two-week-course-route }

This local course adapts Hugging Face Agents Course Unit 1, its starter, and Unit 2.1 for Groq and local execution. Weeks 1–2 cover Unit 1; Week 03 deepens the smolagents and tool work from Week 2 through Unit 2.1. Lessons are available in English and Japanese. External HF lesson pages are optional references. Original HF quizzes remain external activities.

| Week | Focus | Suggested time | Evidence of completion |
| --- | --- | --- | --- |
| [1](week-1-learning-plan.md) | Concepts, local setup, three-stage dummy agent | 3–4 hours | Explain the loop and run `dummy_agent.py` with a real function observation |
| [2](week-2-learning-plan.md) | Working chat template, CodeAgent, time and search tools | 3–4 hours | A model response, direct tool tests, executed agent calls, and a verified source |
| [3](week-3-learning-plan.md) | Introduction, terminal CodeAgent programs, action formats, and function/class tools | 3–4 hours | Saved Python files, direct tool checks, executed agent calls, and a tool modification |
| [4 — coming next](week-4-preview.md) | Retrieval agents and later topics | To be added | Continue after Week 03 |

The [custom-tool challenge](first-agent-practical.md#6-optional-create-your-own-tool) is an optional 30–60 minute extension in Week 2. Durations are planning estimates, not timers; setup and service limits may extend them.

## How to review your progress { #how-to-review-your-progress }

Use the [Week 1 checks](week-1-learning-plan.md#week-1-completion), the [Week 2 practical checks](quizzes.md#finish-the-practical), and the [Week 03 checks](week-3-completion.md). This documentation site does not store progress, quiz scores, or completion status. Keep your scripts and execution evidence for review. Changing language opens the same lesson and does not change your work.

Image generation and the account-gated final quiz are removed. The Week 2 custom tool is optional; Week 03 has its own required guided custom-tool exercise. Publishing a Space and obtaining HF certification are not completion requirements.
