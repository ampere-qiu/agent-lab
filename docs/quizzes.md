# Quick quizzes and completion { #quick-quizzes-and-completion }

This adaptation uses only the two original Hugging Face quick quizzes. They open on the external site and retain its questions and feedback.

| When | Activity |
| --- | --- |
| After the introduction to agents | [Quick Quiz 1](https://huggingface.co/learn/agents-course/en/unit1/quiz1) |
| After models, messages, and tools | [Quick Quiz 2](https://huggingface.co/learn/agents-course/en/unit1/quiz2) |

The final quiz requires account access in the reported setup and is excluded from this course route. No Hugging Face certification or final-quiz submission is required. The local lessons and practical do not depend on external lesson pages.

If a quick quiz fails to load, open it in a regular browser tab and reload. Continue with the local exercise while the external activity is unavailable. This guide does not record scores or award an official Hugging Face certificate.

## Finish the practical { #finish-the-practical }

For Week 1, use the [dummy-agent completion checks](week-1-learning-plan.md#week-1-completion).

For Week 2, after [building your tools](first-agent-practical.md), check that you can:

- Identify a real timezone-tool call and its returned time.
- Identify a real web-search call and open a relevant returned source.
- Explain the roles of the model, Groq, smolagents, and local functions.
- Distinguish a tool error from a successful observation.

These are practical completion checks, not a replacement final quiz. A custom tool is optional; image generation is not included.

Also demonstrate a successful template response, show how to stop and restart the app, and explain the difference between the manual dummy loop and CodeAgent. Record unavailable live checkpoints as incomplete and return to them later. See the [two-week course route](course-route.md).
