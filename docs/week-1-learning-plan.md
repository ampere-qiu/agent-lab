# Week 1 course route

This local course adapts the Hugging Face starter and concepts for Groq API availability and local execution. Image generation and the account-gated final quiz are removed.

1. [Basic setup](prepare-your-computer.md): Python and your Groq key.
2. Foundations: read [our lesson notes](unit-1-walkthrough.md) alongside the [original Hugging Face lessons](https://huggingface.co/learn/agents-course/en/unit1/introduction), and complete the two original HF quick quizzes linked in our notes.
3. [Dummy steps 1–3](dummy-agent-local.md): model request, proposed action, and a function observation.
4. [Template download](run-your-first-agent.md) and [explanation](understand-the-template.md).
5. [Core practical](first-agent-practical.md): register and verify time and web search.
6. [Completion checks](quizzes.md#finish-the-practical).

A custom tool is an optional extension. External HF lesson pages are optional source references; the practical does not depend on them.
