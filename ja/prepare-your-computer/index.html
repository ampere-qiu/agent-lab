    PCの環境を準備する¶

    第1週の基礎を読んだ後、ダミー演習に入る前に設定します。この段階で必要なのはPythonとGroqキーだけです。完全なテンプレートをダウンロードするのは、ダミー演習の3段階を終えてからです。

    1. Python 3.11をインストールする¶

    Windows¶

    コマンドプロンプトを開き、次を実行します。コマンドは1つずつ実行してください。

    winget install --exact --id Python.Python.3.11

    インストーラーの指示を確認し、コマンドプロンプトを閉じて開き直してから、バージョンを確認します。

    py -3.11 --version

    wingetが使えない場合は、Python 3.11.9のリリースページのFilesから、x64 PC用のWindows installer (64-bit)をダウンロードします。実行してAdd python.exe to PATHとPython launcherを有効にし、インストール後にコマンドプロンプトを開き直してpy -3.11 --versionを試します。このガイドのWindows用コマンドは、PowerShellではなくコマンドプロンプトで実行します。

    Mac¶

    Terminalを開きます。Homebrewが入っていれば、次を実行します。

    brew install python@3.11

    Homebrewがなければ、公式のインストール手順を最後の設定まで行ってから再試行します。

    インストールを確認します。

    python3.11 --version

    確認：Python 3.11.xと表示されます。Macのpython3が古い版を指していても構いません。以下ではpython3.11を使います。

    2. ダミー演習用のフォルダーを作る¶

    自分のOS用のコマンドを、ターミナルで1つずつ実行します。

    Windows — コマンドプロンプト¶

    mkdir "%USERPROFILE%\agent-course\dummy-agent"
cd /d "%USERPROFILE%\agent-course\dummy-agent"
py -3.11 -m venv .venv
.venv\Scripts\activate.bat
python --version

    Mac — Terminal¶

    mkdir -p ~/agent-course/dummy-agent
cd ~/agent-course/dummy-agent
python3.11 -m venv .venv
source .venv/bin/activate
python --version

    仮想環境は、この演習用のPythonライブラリを他の作業と分けておく仕組みです。.venvを作る操作で環境を用意し、有効にする操作で、そのターミナルから使う環境を選びます。ダミー演習と第2週のテンプレートでは、それぞれ専用の環境を使います。

    フォルダーがすでにあれば、作り直さずそこへ移動します。仮想環境も作成は一度で十分です。

    確認：ターミナルに(.venv)が付き、Python 3.11.xと表示されます。このウィンドウを開いたままにします。

    3. モデル用クライアントを入れる¶

    どちらのOSでも次を実行します。

    python -m pip install "openai>=1.0,<3"

    最後にエラーが出ず、通常の入力待ち表示に戻るまで待ちます。このライブラリは互換APIを通じてGroqに接続します。OpenAIアカウントは不要です。

    4. Groq APIキーを作る¶

    自分のアカウントでGroq Consoleに登録・ログインします。無料プランには利用制限があります。

    A. キーの画面を開く¶

    1. ブラウザーでGroq Consoleにログインします。
    2. ナビゲーションのAPI Keysを開くか、API Keysの直接リンクを使います。
    3. Create API Keyをクリックします。
    4. 名前にagents-courseなど用途が分かる名前を入れます。有効期限を選べる場合は授業期間をカバーするものを選びます。
    5. ダイアログの作成・送信ボタンで確定します。
    6. 生成された秘密のキーをコピーし、起動時に取り出せるようパスワードマネージャーなどに保管します。他の学生と共有したり、このガイド、ソース、チャットに貼ったりしないでください。

    agents-courseはラベルにすぎません。実際に使うのは生成された秘密の値です。画面の表記は変わる場合があります。公式クイックスタートにもキー作成へのリンクがあります。

    確認：自分のGroqキーを用意できました。ただし、キーを作っただけではモデルを選択したことにも、リクエストの成功を確認したことにもなりません。

    ダミースクリプトはターミナルの非表示入力でキーを求めます。完全なエージェントでも同じキーを使います。Pythonファイルには書かないでください。

    5. ダミー演習へ進む¶

    必要なら基礎と小テストを終え、ダミー演習の3段階に進みます。ここではまだapp.py、Gradio、完全なエージェントのZIPは必要ありません。

    別の日にダミー演習を再開する¶

    Windowsの場合：

    cd /d "%USERPROFILE%\agent-course\dummy-agent"
.venv\Scripts\activate.bat

    Macの場合：

    cd ~/agent-course/dummy-agent
source .venv/bin/activate

    演習でファイルを作成した後、python dummy_agent.pyで実行し、求められたらキーを入力します。結果はブラウザーのチャットではなくターミナルに出ます。
