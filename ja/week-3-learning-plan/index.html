    第03週 · 学習計画とダウンロード¶

    今週は、smolagentsと自分のGroqキーを使い、小さなPythonエージェントをターミナルで動かします。題材は、アルフレッドのパーティー準備です。音楽の検索、メニューの選択、準備時間の計算、ケータリングやテーマを選ぶツール、ローカルの知識ベースからの検索・取得に取り組みます。

    smolagentsの概要、CodeAgent、アクションの形式、ツール、Agentic RAGを扱います。エージェントのチームと画像・ブラウザの話題は第04週に続きます。

    学習目標¶

    小さなエージェントプログラムを作成・実行し、アクションと観測結果を見分けられるようになります。Pythonコードと構造化されたツール呼び出しの違いを説明し、Pythonツールのデータを変更し、取得した文章と出典を基にRAGの回答を確かめられることを目指します。

    用意するもの¶

    第2週で使ったFirst_agent_templateフォルダー、Python 3.11の.venv、コードエディター、Groq APIキーを使います。Groqへの問い合わせとウェブ検索にはインターネット接続が必要です。

    今週のプログラムはターミナルだけで動かし、結果もそこに表示します。 第03週のためにGradioやブラウザのチャット画面を起動する必要はありません。この教材サイトでは手順を読みます。

    今週の進め方¶

    レッスン 取り組むこと
    08 · smolagents入門 モデル、フレームワーク、ツールの役割を読む。
    09 · CodeAgentを動かす 音楽検索、メニュー選択、準備時間のプログラムを作って動かす。
    10 · Pythonコードと構造化ツール呼び出し 2種類のアクションを比べ、ToolCallingAgentを動かして実行記録を読む。
    11 · 関数とクラスで作るツール 直接テストと2つのエージェントを作り、ツールのデータを変える。
    12 · Agentic RAGシステムを作る ウェブとノートを検索し、出典を確認してノートを追加する。
    13 · 完了確認 保存したファイルと実行結果を示す。

    1. 補助ファイルをダウンロードして配置する¶

    何が入っていますか？ ZIPには7つの補助ファイルが入っています。Groqへの接続、用意済みのPythonツール、ローカル知識ベースの検索ツール、パッケージ一覧、手順書、原典のライセンスです。小さなエージェント本体は、レッスンのコードを使って自分で作ります。

    第03週の補助ファイルをダウンロード（.zip）

    ZIP内のファイル 役割
    week03_common.py Groqへの接続、エージェントの設定、結果・エラーの表示。
    week03_tools.py メニュー、ケータリング、パーティーテーマのツール。
    week03_search.py ウェブ検索ツール。
    week03_retriever.py 5つのパーティーノートと、ローカルのBM25検索ツール。
    week03-requirements.txt 今週必要なPythonパッケージの一覧。
    week03_README.md 環境準備と実行の手順書。
    week03-HF-LICENSE.txt Hugging Faceの原典のライセンス。
    1. 第2週のチャットアプリが動いていれば、そのターミナルでControl + Cを押して停止します。
    2. ダウンロードボタンを押します。通常、ZIPはダウンロードフォルダーに保存されます。
    3. Windows：ZIPを右クリック → すべて展開 → 展開。Mac：FinderでZIPをダブルクリックします。
    4. 展開されたweek03-exercisesフォルダーを開き、中の7ファイルをコピーします。
    5. 既存のFirst_agent_templateフォルダー内、app.pyと同じ場所に貼り付けます。week03-exercisesフォルダーごとではなく、中のファイルだけをコピーしてください。以前のweek03...ファイルを編集している場合は、同名ファイルを置き換える前に編集内容をバックアップします。

    ファイル管理画面で、コピー先を開きます。

    • Windows — エクスプローラー：アドレス欄に%USERPROFILE%\agent-course\First_agent_templateを貼り付け、Enterを押します。
    • Mac — Finder：移動 → フォルダへ移動を選び、~/agent-course/First_agent_templateを入力してReturnを押します。

    これは第2週の標準の保存場所です。別の場所に保存した場合は、その既存フォルダーを使ってください。空の代替フォルダーを新しく作る必要はありません。

    コピー後は、7ファイルが既存のapp.pyや.venvフォルダーと並びます。ZIPには補助処理とツールが入り、それらを使うmy_...pyプログラムの作り方はレッスンにあります。

    2. エディターでプロジェクトを開く¶

    コードエディターを開きます。VS Codeではファイル → フォルダーを開くからFirst_agent_templateを選びます。ファイル一覧にapp.py、week03_common.py、week03_tools.py、week03_search.pyが並んでいることを確認してください。

    レッスンでファイルを作成するとあったら、ファイル → 新しいテキストファイルを選び、示されたPythonコード全体を貼り付けます。ファイル → 名前を付けて保存で、指定された名前でこのフォルダーに保存します。保存先はapp.pyと同じ場所です。.venvやtoolsの中には保存しません。

    編集後はWindowsでCtrl + S、MacでCommand + Sを押します。my_playlist.py.txtではなく、my_playlist.pyという名前にしてください。

    3. ターミナルを開いて環境を有効にする¶

    Windows：スタートでコマンドプロンプトを検索して開きます。Windows用のコマンドは、PowerShellではなく、このコマンドプロンプトのウィンドウで実行してください。

    cd /d "%USERPROFILE%\agent-course\First_agent_template"
.venv\Scripts\activate.bat
python --version
dir

    Mac：ターミナルを開いて実行します。

    cd ~/agent-course/First_agent_template
source .venv/bin/activate
python --version
ls

    1行ずつ実行します。(.venv)が表示され、Pythonが3.11.xで、一覧に配布されたweek03...ファイルがあることを確認します。現在のフォルダーはFirst_agent_templateです。

    新しいターミナルを開いたら、cdと環境の有効化をやり直します。実習中はこのターミナルを開いたままにしましょう。この後のレッスンでは実行：python filename.pyとだけ示します。WindowsでもMacでも、この環境を有効にしたFirst_agent_templateのターミナルで実行します。

    4. 必要なパッケージを確認する¶

    Windows・Mac共通で、環境を有効にした同じターミナルで実行します。

    python -m pip install -r week03-requirements.txt

    smolagents==1.13.0、openai>=1.0,<3、ddgs==9.16.0を引き続き使い、ステップ12用にlangchain-community==0.4.2、langchain-text-splitters==1.1.3、rank-bm25==0.2.2を追加します。Gradioの画面、GPU、埋め込みモデル、ブラウザ自動操作は導入しません。既存のパッケージはRequirement already satisfiedと表示されることがあります。検索用パッケージとその依存先はダウンロードが必要になる場合があります。

    続いて、Groqを使わずに、配布されたメニューツールを確認します。

    python -c "from week03_tools import suggest_menu; print(suggest_menu(occasion='formal'))"

    表示される結果：

    3-course dinner with wine and dessert.

    これは「ワインとデザート付きの3コースディナー」という意味です。フォルダー、読み込み、Pythonツールが動くことを確認しています。LLMへの問い合わせは行いません。

    自分で作るファイル¶

    ステップ First_agent_template内に作るファイル 役割
    09 my_playlist.py CodeAgentでパーティーの音楽を検索する。
    09 my_menu.py エージェントで保存済みのメニューを選ぶ。
    09 my_timing.py Pythonで準備の終了時刻を計算する。
    10 my_tool_calling.py 構造化ツール呼び出しで音楽検索を動かす。
    11 my_tool_check.py LLMなしでメニュー・ケータリング・テーマを直接テストする。
    11 my_catering.py エージェントで架空の最高評価の業者を選ぶ。
    11 my_theme.py クラス型ツールからパーティーテーマを取り出す。
    12 my_rag_search.py ウェブ検索の結果からパーティーの計画を作る。
    12 my_retrieval_check.py LLMなしでローカル検索とその制約をテストする。
    12 my_rag.py 取得した出典ラベルとローカルノートを使って答える。

    各実習には、コード全体、ファイル名、短い実行コマンド、出力の確認点を示しています。環境の準備は上の手順を共通して使います。読むだけと書かれた短いコードは、用意済みの関数や実行時の出力です。追加のプログラムとして作る必要はありません。

    動かないとき¶

    メッセージや症状 確認すること
    フォルダーが存在しない ファイル管理画面で実際のFirst_agent_templateの場所を探し、その場所を指定します。
    .venvの有効化ファイルが見つからない フォルダーが違う可能性があります。第2週で使ったプロジェクトと環境を使います。
    can't open file 指定の.pyファイルをapp.pyと同じ場所に保存します。綴りと、.py.txtになっていないかを確認します。
    No module named week03_common ZIPの中身を、新しいプログラムと同じ場所に置きます。下位フォルダーに入れないでください。
    No module named smolagents、openai、ddgs .venvを有効にし、上のパッケージ導入コマンドを実行します。
    langchain_communityやrank_bm25など、検索用モジュールが見つからない 更新版の一覧を使い、実行と同じ.venvでパッケージを導入します。
    Groqキーを入力しても何も見えない 入力は非表示です。キーを入力してEnterを押します。
    Groqへの問い合わせや検索が失敗する 実際のエラーを教員に見せ、第2週のトラブル対処を確認します。
