    第04週 · smolagents Part 2¶

    目標：検索の根拠を振り返り、複数のエージェントを連携させ、画像やスクリーンショットを根拠として使います。

    始める前に：第03週を終えてください。第03週の作業はFirst_agent_templateに残し、第04週は別のweek04-exercisesフォルダーを使います。教材はこのサイトで読み、Pythonファイルはコードエディターで作り、ターミナルで実行します。

    学習の流れ¶

    トピック 目標
    14 · 第03週のRAGを確認する 取得した文章が回答を裏付けるか確認します。RAGのコード作成は第03週で行います。
    15 · マルチエージェントとBatman演習 管理役とWeb調査役を作り、連携させます。
    16 · 画像・ブラウザエージェント 画像と更新されたスクリーンショットを使うエージェントを作ります。
    17 · 完了確認 コードを説明し、実行結果を確かめます。

    注：すべてのトピックに取り組んでください。トピック15でエージェントをもう1体追加する課題は任意です。

    1. ダウンロードして配布ファイルを確認する¶

    第04週の教材と補助ファイルをダウンロード

    Batman用ダウンロードと画像・ブラウザ用ダウンロードも同じ内容です。ZIPは1つだけダウンロードして展開してください。

    1. ZIPを保存します。通常はダウンロードフォルダーに入ります。
    2. Windows：右クリック → すべて展開 → 展開。Mac：FinderでZIPをダブルクリックします。
    3. 展開されたweek04-exercisesフォルダーを開きます。外側にもう1つフォルダーができた場合は、その中のweek04-exercisesを開いてください。requirements.txtとweek04_common.pyが同じ場所にあれば正しいフォルダーです。
    4. フォルダーごと既存のagent-courseへ移し、First_agent_templateと並べます。標準の場所はWindowsでは%USERPROFILE%\agent-course\week04-exercises、Macでは~/agent-course/week04-exercisesです。別の場所を使っている場合は、以降のコマンドのパスを自分の場所に合わせてください。

    すでに第04週を始めている場合：作業のコピーを保存してから、最新のZIPを新しいフォルダーへ展開してください。この教材のコードと、そのZIPに入っている補助ファイルを一緒に使います。

    ZIPに入っているファイル — 既存のファイルを開いて使います。作り直す必要はありません。

    配布物 役割
    README.md、NOTICE.md、HF-LICENSE.txt 使い方、出典・変更内容、HFのライセンスです。
    requirements.txt インストールするパッケージの一覧です。
    week04_common.py Groqに接続し、エージェントの結果をターミナルに表示します。
    week04_search.py 調査回数の上限内でウェブを検索し、ページの短い抜粋を読みます。
    week04_tools.py 貨物輸送時間の概算とHTMLレポートの作成を行います。
    week04_browser.py ローカルページの操作とスクリーンショットの取得を行います。
    prepare_visuals.py 練習用の会場図とウェブページを作成します。
    lessons/en、lessons/ja 日英の教材と、出典を記したHFの図が入っています。

    これから追加するファイル：手順に沿ってevidence.md、evidence-filesフォルダー、各my_*.pyを作ります。環境準備で.venvとassetsができ、後の実行でoutputsが作られます。

    2. エディターを開いて環境を準備する¶

    VS Codeのファイル → フォルダーを開くでweek04-exercisesを選びます。ファイル一覧でrequirements.txtとweek04_common.pyを確認してください。配布されたPythonファイルはそのまま残し、同じ場所に自分のmy_*.pyを作ります。

    Python 3.11、既存のGroqキー、インストール・モデルへの問い合わせ・検索に使うインターネット接続、トピック16用のChromeが必要です。次のコマンドを1行ずつ実行してください。標準と異なる場所へ展開した場合は、実際のフォルダーのパスに変更します。

    Windows — コマンドプロンプト（PowerShellではありません）：

    cd /d "%USERPROFILE%\agent-course\week04-exercises"
py -3.11 -m venv .venv
.venv\Scripts\activate.bat
python --version
dir
python -m pip install -r requirements.txt
python prepare_visuals.py

    Mac — ターミナル：

    cd ~/agent-course/week04-exercises
python3.11 -m venv .venv
source .venv/bin/activate
python --version
ls
python -m pip install -r requirements.txt
python prepare_visuals.py

    prepare_visuals.pyの役割：LLMやネットワークを使わず、架空の会場図とローカルの練習ページを作ります。assets/venue.pngとassets/venue.htmlが生成されます。これらを手作業で作る必要はありません。次のように表示されます。

    Created assets/venue.png and assets/venue.html (no LLM).

    先へ進む前に：プロンプトに(.venv)が表示され、Pythonが3.11.xで、インストールが完了していることを確認します。ファイルマネージャーでassets内の2つのファイルを確認し、assets/venue.pngを開いてください。インストールが失敗した場合は、そのエラーを解決してから次のプログラムを実行します。

    このターミナルは開いたままにします。以降の実行：python filename.pyは、環境を有効にしたweek04-exercises内のターミナルで行います。新しいターミナルを開いた場合は、上のcdと環境の有効化の行を再実行してください。.venvを作り直す必要はありません。練習ページを編集した後は、元に戻したい場合を除きprepare_visuals.pyを再実行しないでください。生成した2つのファイルが上書きされます。

    Seleniumは最初のブラウザ実行時にChrome対応のドライバーを取得することがあります。ドライバーやネットワークのエラーは、トピック16のトラブル対処を確認してください。Groqキーは非表示の入力欄で指定し、コードやメモには保存しません。エージェントが使うタスク文、取得した文章、画像はGroqへ送信されます。

    3. 記録用ファイルを作る¶

    予想、回答、実行結果の短い抜粋を残すテキストファイルevidence.mdを作ります。Markdownは通常のテキストなので、コードエディターで編集できます。ZIPには含まれておらず、Pythonで実行するファイルでもありません。

    1. エディターでファイル → 新しいテキストファイルを選びます。
    2. 下の見出しを貼り付けます。見出しは英語のままにし、各項目への回答やメモは日本語で書いて構いません。
    3. 名前を付けて保存で、week04-exercises内のrequirements.txtと同じ場所にevidence.mdとして保存します。
    4. Ctrl + SまたはCommand + Sで保存します。ファイル名がevidence.md.txtではなくevidence.mdになっていることを確認してください。
    5. エディターのファイル一覧またはファイルマネージャーで新しいフォルダーを選び、week04-exercises内にevidence-filesを作ります。比較に使うレポートやスクリーンショットのコピーを保存します。
    evidence.md — create this text file
    # Week 4 evidence

## Topic 14 — Week 3 RAG review
- Evidence used: Week 3 run or provided example:
- Answers 1–5:

## Topic 15 — Batman team
- What each agent does and what evidence it returns:
- Build checks A–D: agent count, tools and managed-agent connection:
- One-location handoff: request, actions, observations, returned evidence:
- Full report: sources checked and one recalculated estimate:
- Code-reading answers, checked sources and limitations:
- Optional verifier: design, false-claim test and verdict (or not attempted):

## Topic 16 — Vision and browser
- My image predictions, supported facts and uncertainty:
- How each agent receives its image or screenshot:
- Initial image run and step-free-route comparison:
- Direct browser check: before.png versus after.png:
- Agent browser run: actions, screenshot names and supported answer:
- Edited-page run: exact change, prediction, archived results and comparison:

## Topic 17 — Review
- Status for each required checkpoint: complete or incomplete, with reason:
- Answers 1–5:

    作業を進めながら、対応する見出しの下に回答や結果を追加します。ターミナルから短い抜粋をコピーし、エラーも記録してください。まず自分で問題に答え、その後で解答を開いて考え方を確認します。

    トピック 作成するもの 作成するタイミング

    14 新しいPythonファイルは不要 第03週の出力または教材の例を使って問題に答えます。
    15 my_batman_tools.py ツールを直接確認する前に作ります。
    15 my_batman.py 4A〜4Dに沿って2体のエージェントとタスクを追加します。
    15・任意 my_batman_verified.py 検証役の追加に取り組むとき、動作しているチームのコピーを作ります。

    16 my_browser_check.py ブラウザ操作を直接確認する前に作ります。

    Pythonが作成するもの：.venvは環境準備、assets/venue.pngとassets/venue.htmlはprepare_visuals.py、before.pngとafter.pngはmy_browser_check.py、outputs/batman-report.htmlはレポートツール、outputs/browser-*.pngはスクリーンショットのコールバックが作成します。該当する処理が成功するまでは、ファイルがなくても正常です。同じ名前の出力は再実行で上書きされることがあるため、各レッスンの手順で必要なコピーを残してください。

    最初のエージェントを実行する前に¶

    配布された補助ファイル、生成した会場図とページ、作成したevidence.mdとevidence-files、有効化したターミナルを確認します。my_*.pyは各レッスンで1つずつ作ります。配布されたREADME.mdにも準備の要点があります。

    モデルのエラーが401ならキー、403/404ならモデルへのアクセス権を確認します。429では実行を止め、利用枠の回復を待ってください。チーム全体を繰り返し再起動しないでください。ステップ上限後に最終回答が表示されても、ターミナルのツール呼び出しと観測結果を確認する必要があります。
